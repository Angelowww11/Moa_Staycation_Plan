# Manila After Dark

An interactive family guide for a Metro Manila staycation from December 26, 2026 through January 3, 2027. The suggested itinerary is flexible; the original accommodation notes end on January 2, so January 3 is marked as an optional extra day.

## Run locally

```bash
npm install
npm run dev
```

Open `/app.html` for the editable development version. `npm run build` also refreshes the production files at the repository root so GitHub Pages works whether it serves the branch or the Actions artifact.

The budget calculator stores selected stops in this browser. Costs are per person and exclude commute and lodging. Venue ticket prices link to primary sources when available; other costs are planning estimates and should be confirmed before booking.
